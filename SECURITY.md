# Security policy

Report vulnerabilities in this layer, or in the software it ships, privately by
email to the maintainer:

- Stefano Viola <stefano.viola@toradex.com>

Please include the affected recipe and version, the release branch, and how to
reproduce the issue. You get an acknowledgement within a week. Vulnerabilities in
Arduino's software itself are also reported to Arduino.

Supported branches: the branch of the current Yocto release (`wrynose`).
